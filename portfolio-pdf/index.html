关于我

当未来的数据足够全面、技术足够精湛，我们仍需要一颗柔软而敏锐的心。设计的思维，正是那份灵光闪烁的创造力——它不靠堆砌功能，而在于唤醒人与生活之间，那场关于美的对话。

设计从真实的移动与现场里长出来。我习惯在持续的移动中收集对现实的判断：天气的转变、社群的节奏、陌生人说话的方式，以及一块光落在材质上的角度——这些只活在身体记忆里的信息，最终决定了一个数字产品沉淀下来的体验。

01 · AMADEUSSystem Architecture
AMADEUS
系统架构 · How She Works
开口之前，系统已经想好怎么相处
八个模块，在每一句话之前依次运行
01
人格档案 Soul口吻 / 边界 / 传记三层文件，每轮按序注入上下文。
02
分室记忆 MemoryHall / Lab / Cafe / Forbidden 按语义分室检索，不混池。
03
情绪矩阵 PAD愉悦 / 唤醒 / 支配 + 关系强度，跨轮延续不重置。
04
情绪曲线 Curve把内部状态合成一条可见信号，不靠猜测 prompt。
05
行为仲裁 Behavior开口前在靠近 / 防御 / 收缩之间打分竞争。
06
主动层 Drive空闲时先开口，且下一轮必须接回上一句。
07
心智加工 Mind逻辑 → 共情 → 智识，贴着本轮焦点说话。
08
产品界面 UI对话在前、机制可见，确认她为何这样回应。
愿景 从对话里的在场，走向生活里的在场——接入家居联动、实体投影与 AR，先把长期陪伴做实。
