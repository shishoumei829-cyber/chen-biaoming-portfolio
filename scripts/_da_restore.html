我发现的问题

老龄化与突发离别每天都在发生——市面上的「数字人」却多半只有一张嘴：口吻像了，判断、记忆与关系习惯没有留下。关掉窗口，关系就结束；更像角色扮演，而不是可被托付的数字人格。

我的思考

死亡不是终点，遗忘才是。方舟要承载的是一个人的判断方式、情绪节奏与有质感的经历——让告别之后仍能说：对，这是她会说的话、会做的选择。

01 / 设计立场

不是模仿表面，
是复刻底层。

一个人之所以是他自己，不只因为说了什么，而是因为有一套稳定的内部运作。现有系统多在复制输出；我要建模的是驱动输出的内部结构——从真实的人身上提取可运行的判断引擎。

01行为先于描述——用价值冲突与具体情境归纳，人对自己的描述常不准，行为会暴露真实结构。
02经历塑造判断——采集有情绪重量、改变了判断方式的经历；记忆用来塑造判断，不是挂检索标签。
03动态优于静态——建模「在 X 情境下倾向于 Y」，冲突时动态权衡，对应 CAPS 与四变量决策。

我的解决

用情境与行为暴露结构，用经历塑造判断，用纠错迭代拟合——每一次表达都从内部状态长出来，而不是贴标签检索。

02 / 系统架构

可运行的仓库，
不是概念图。

Node.js + Express 本地服务，Ollama 推理，数据落在用户目录。五层负责采集与分工，CAPS 负责运行时加工，Prompt 组装把 PAD、RAG、核心人格与行为签名写进同一条 system 上下文。

用户输入 + 关系深度 + PAD + 先例记忆 ↓ CAPSEngine.parseSituation → corePersona.processCAPS ↓ 五层权重 · 核心 8 维 · RAG / 个人记忆检索 ↓ buildDigitalTwinPrompt → Ollama /api/chat ↓ 表达层对白（训练 / 陪护模式分支）

04 / CAPS 与单轮流水线

情境进，

function runPersonaCapsPipeline(userQuery, options = {}) {
  const relScore = memorySystem.getRelationshipScore();
  const engine = new CAPSEngine(corePersona);
  const situation = engine.parseSituation({
    user_text: userQuery,
    relationship_depth: relScore,
    emotion_valence: currentPAD.P,
    event_nature: options.event_nature || 'mixed'
  });
  const precedent = memoryInfluence.findPrecedent(userQuery, …);
  const capsResult = corePersona.processCAPS({ …, precedent_memory: precedent });
  capsSediment.recordActivation(capsResult, userQuery);
  return { capsResult, precedent, sediment, situation };
}
05 / Prompt 组装

人格写进 system，
不是贴一句人设。

buildDigitalTwinPrompt 把核心摘要、CAPS 行为签名、PAD 自然语言、RAG 命中与纠错反馈合并；陪护模式强制诚实标明数字分身，训练模式用于试聊校准。

lib/prompt-builder.jsbuildDigitalTwinPrompt
function buildDigitalTwinPrompt(ctx) {
  const identity = ctx.mode === 'companion'
    ? `你是${trainee}的数字分身「${name}」…不是真人实时在线。`
    : `你正在扮演${trainee}的数字分身进行试聊…用第一人称「我」。`;

  let body = `${identity}
【人格特征】${traitBlock}
【核心人格】${corePersonaSummary}
${capsContext}
当前情感状态：${padDesc}`;

  if (ragContext) body += `\n检索到的训练资料：\n${ragContext}`;
  // 回复要求：第一人称 · 不冒充真人 · 保持语气
  return body;
}
06 / 训练体系

冷启动、日常积累、
校准迭代。

导入文字提取音色初值，同步启动价值冲突游戏化采集；日常按状态与空白动态出题；试聊后像/不像的纠错比凭空描述更真实。

1冷启动：聊天记录与日记入库，价值冲突暴露认知优先级；追问「为什么」，理由比选择更有价值。
2日常积累：当下捕捉碎片，系统追问加厚——不要求一次性回忆整个人生。
3校准迭代：「在 X 情境下应是 Z 而非 Y」写入核心修正；盲测里程碑检验拟合度。
07 / 伦理与边界

温暖可以真实，
来源必须诚实。

不是有意识的存在，不能冒充真人实时在线。能做到的是足够有根的投影、有质感的记忆与本地私密；做不到的是感官质感与真正的自我成长。

Companion · 伦理

数字分身

我始终在这里。你知道对面是我，不是真人实时在线——温暖可以真实，来源也必须诚实。

我的愿景

为预防意外、为告别后仍能被想起、为自我探索的一面镜子——与 AMADEUS 实验同源的可观测中间层；数字方舟，是把「在场」做成可训练、可陪护、可留在本机的产品。
