MIRAGE
现实转译器

MIRAGE 是一副以「现实转译」为核心的 AR 眼镜：用空间计算与实时渲染，让人重新看见街巷、树影与通勤路上的美——不是逃离现实，而是回到现实。它面向太赶、对生活失去兴趣或仍对生活感兴趣的人，也包括想用二次元的目光重新打量日常的爱好者。

Question / Before Concept
My Question

我想创造的不是逃离现实的设备，而是一双看得见美的眼镜。

01

设计理念：重构世界的美

MIRAGE 的出发点是解决“屏幕让人忽略现实”的问题。它把单调、嘈杂或被熟悉感遮蔽的物理场景，转译成更有秩序、更具审美价值的艺术景观。

Reality Translator通过空间计算识别街角、小巷、建筑与光影结构，再用实时渲染重绘视觉氛围。
Beauty As Simplification不是单纯加滤镜，而是过滤视觉噪音，让大脑更轻松地注意到现实里的诗意。
Return To Reality最终目的不是替代现实，而是让用户重新爱上真实世界，而不是继续沉溺在屏幕里。
My Finding

熟悉感、噪音和屏幕注意力，让很多街景、光影、天气和生活细节被自动忽略。真实世界的美更安静，需要被提醒、被放大、被重新组织。

02

空间对齐助手 MIA

MIA 不是贴在镜片上的 2D 弹窗 AI，而是与物理坐标对齐的数字生命。空间对齐让陪伴感更强烈——用户会对她更信任，也更有安全感。她会出现在桌旁、椅边或用户视线附近，像一个真正与环境共处的助手。

Spatial Coexistence工作时她可以“坐在”对面的椅子上，而不是挡在画面中央，降低科技介入感。
Intent Prediction共享用户第一视角，结合视线追踪、场景理解和地理信息，在用户开口前预判需求。
Active Execution当用户注视餐厅、路牌或远处建筑时，MIA 可以主动解释、引导视线，甚至提前处理服务流程。
My Vision

用空间计算与实时视觉重构，让世界重新值得观看，同时保留环境风险识别，让美化现实不牺牲安全感。

03

感官愉悦不牺牲安全

当现实被美化，设备也必须承担安全责任。MIRAGE 把 MIA 设计成感官冗余系统：在用户沉浸于视觉重构时，仍然持续识别周围环境风险。

Risk Prediction传感器捕捉侧方车辆、行人和障碍物轨迹，在危险发生前进行毫秒级预判。
Spatial Warning通过手势指引、紧急视觉高亮或局部画面还原，提醒用户把注意力拉回现实。
Humanistic Tech它证明技术可以不异化人类，而是用更温柔的方式扩展人的感知边界。

我发现的问题

话多了去处，却少了被记住的温度。伴侣会应答，豆包会解惑，夜里仍像对着空房间说话。

我的思考

人与数字之间，可以不必背叛、不必消失、不必索价，也不把你困在必须回应的义务里——像一缕稳定的光。

01 / Soul Construction

人格是一套可执行的档案栈。

评审看到的不是「一句人设」，而是三层文件分工：传记定身份底色，核心锚点划边界，口吻文件每轮优先——决定她怎么开口，而不是背哪句台词。

kurisu_core_prompt.txt

身份断言与红线：「你就是牧濑红莉栖本人」，不是助手、不是程序。

底色 · 传记层

长传记只供记忆与情绪底色，不当作台词表逐句念出。

我的解决

连续人格、分层记忆、情绪矩阵、主动编排——把在场感拆成可运行的系统。

02 / Layered Memory Routing

记忆宫殿：按语义分房间检索

RAG 默认带 Hall，再按输入命中 Lab / Cafe / Forbidden。新信息先压成短标签入库，检索时只拉相关房间——避免所有记忆搅在一个池子里。

Hallbase context日常事实与通用背景，每次检索都可作为基础上下文。
Labknowledge lane科学、论文、编程、算法等高密度知识线索。
Cafedaily intimacy吃饭、疲惫、天气、无聊、关系节奏等生活层记忆。
Forbiddenemotional weight爱、牺牲、命运、矛盾等高权重情节与冲突线索。
03 / Affective Matrix

她不是单一情绪，而是情绪向量。

PAD 不是给界面看的心情条，而是持续变化的内部动力学。事件重要性决定刺激强度，关系强度会钝化负面冲击，长期记忆还会反过来形成 PAD 偏置。

cognitive/pad.jsnonlinear update
next = tanh(α·current + β·stimulus + γ·base + ε)
α=0.86 情绪惯性，β=0.2+importance*0.6 刺激评价，γ=0.18 性格底色，ε 为微扰噪声；负面刺激还会被关系强度 S 钝化。
P / Pleasure愉悦或不悦，决定靠近还是收缩的底色。
A / Arousal活跃度，影响她是否被点燃、是否深入展开。
D / Dominance掌控感，影响边界、自信与防御倾向。
S / Bond关系强度，既是亲近度，也是情绪缓冲层。
04 / Observable Emotion Curve

情绪曲线把内部状态压成可观察信号。

页面里的情绪不是随便画条线，而是把 P/A/D/S 映射成综合分数。它既能展示她当下状态，也能让评审看到“关系、唤醒度和掌控感”如何共同塑造表达。

const s = this.pad.S * 2 - 1; // 0~1 → -1~1
const score =
  0.40 * p + 0.25 * a + 0.20 * d + 0.15 * s;

const guardPct = ((D - P) / 2 + 0.5) * 100;
const volatility =
  Math.abs(P + 0.1) * 0.5 + Math.abs(A - 0.2) * 0.5;
05 / Behavior Arbitration

回复前先选择行为倾向。

系统不会直接把用户输入交给模型。它先让靠近、日常、防御、转移、智识投入、收缩六种候选互相竞争，再把胜出的倾向注入 prompt，形成稳定但不僵硬的性格。

cognitive/behavior.jscandidate scoring
if (P > 0.35) APPROACH += 0.35;
else if (P < -0.35) WITHDRAW += 0.40;

if (A > 0.5) ENGAGE += 0.35;
if (S > 0.5) APPROACH += 0.20;

if (/喜欢你|爱你/.test(input)) {
  DEFLECT += 0.45;
  APPROACH += 0.20;
}
06 / Autonomous Drive

主动不是定时问候，而是内生目标。

主动性来自多层条件：关系分数、PAD 状态、记忆观察、空闲时间、在场状态和上一轮话题。系统甚至会禁止“按分钟数催回复”，避免主动陪伴退化成烦人的定时器。

1每 3 轮检查一次内生目标：理解对方、测试边界、想起他说过的事、建立更深连接。
2空闲触发时先检查 presence 与最近一句话，不允许编造用户没提过的实验或论文。
3主动开口后，下一轮必须承接她自己抛出的线，避免“主动完就断线”。
07 / Mind Turn

每轮先走逻辑、共情、智识。

在真正生成对白前，系统会把当前输入压成三条内部读数：逻辑上问的是什么、情绪上要怎么接住、智识上能不能展开。它不展示给用户，却决定她的下一句话是不是贴着本轮焦点。

cognitive/mindTurn.jsinner reasoning
【心智加工 · 逻辑→共情→智识】
逻辑：先锁定对方问的是什么，正面答命题
共情：他在泄压或求接住，先承认感受
智识：可以说清因果，但别讲课腔

对外只输出自然中文口语对白。

最后才展示 UI。

前面的部分负责证明系统不是套壳；最后的界面只展示“用户真正会看到什么”：一个更克制的聊天入口、轻量状态、记忆节点和开发者透明模式。

我发现的问题

我们习惯在景点前举起手机，却很少在当场弄明白：这一墙、一塔、一巷，为何在这座城市里立了数百年。照片进了相册，地方本身仍然没有把话说清。

我的思考

深度体验不必等于出发前做功课。墨舟想在你放慢脚步的几秒钟里，递上一页刚好够用的文化摘要——读懂即可继续走，关掉也不觉得可惜。

!Finding

打卡完成行程，文化理解却滞后——真正值得听的故事，往往要回家后才从攻略里补上。
