v2.0 · 五模块子系统深度落地

2026 年 6 月 · digital_life_upgrade 路线图第一阶段工程化 · 分支 cursor/module-01-autonomy-3e20 · npm test 50/50

v1.1 补上了每一轮的内心——六维感受、印记、当轮约束。v2.0 补上跨时间的内心生活：自主、进化、理解、具身、元认知五条子系统，由 DigitalLifeOrchestrator 统一编排，各自独立持久化、可观测、可测试。

这次大更新在解决什么

digital_life_upgrade.md 写了数字生命五阶段路线图，仓库里却长期只有模块名、没有完整行为闭环。模块一已是深度子系统，模块二～五仍停在根目录浅层文件；编排时序错位、冲动无法可靠接入行为打分、梦境残念断在生成处、INTERNAL STATE 最初只露自主性一条线。

v2.0 按模块一的同一标准，把五条线全部做成独立子目录 + 独立 JSON 持久化 + getPublicState() + buildPromptBlock() + 行为闭环单测。

编排器三阶段

DigitalLifeOrchestrator
onUserTurn() — 用户轮：自主 / 理解 / 具身 + 进化 RL 记上一轮
afterBehaviorDecision() — 行为后：元认知反思与洞察注入目标
runIdleCycle() — 空闲轮：自主环 + 记忆整理 + 梦境
onVision() — 视觉：环境感知
buildPromptContext() — 汇聚五模块内心碎片进 digitalLifeCtx

五模块一览

模块一 · 自主性 digital_life/autonomy/ 十种内驱力动力学、交叉抑制、冲动生命周期、SPEAK/WAIT/REFLECT 自主环；冲动经英文 intentKey 接入行为打分。
模块二 · 自我进化 digital_life/evolution/ 情节分段与关联图、浅睡/深睡/REM 梦境与 carryover、人格轨迹、RL 桥接在正确时序更新 Q 值与行为偏置。
模块三 · 用户理解 digital_life/understanding/ 共情调节模式、心智模型（BDI 融合）、言外之意检测 → pendingNeed 注入 Prompt。
模块四 · 具身化 digital_life/embodiment/ 环境/时间感知、PAD→表情预设→Live2D sprite、TTS 情绪 hint。
模块五 · 元认知 digital_life/metacognition/ 四域信念与证据链、反思环与偏见检测、洞察 → goalSystem 内生目标。
统一标准 每模块相同 constants + 领域引擎 + XxxSubsystem；{name}_subsystem.json 防抖写入；deprecated re-export 保持旧导入可用。

v2.0 · 与 v1.1 如何叠在一起

两条内心线同时跑

每一轮：六维更新 → 印记 → 约束 → 行为仲裁 → Mind Turn → 模型（v1.1 感受层）
跨轮 / 空闲：五模块子系统在编排器里接续——内驱力、梦境残念、言外之意、表情立绘、元认知洞察同时写入 INTERNAL STATE 与 Prompt。 

用户输入
  → 六维 + 印记（v1.1）
  → onUserTurn：理解 / 自主 / 具身 / 进化(RL)
  → 行为仲裁 + 约束
  → afterBehaviorDecision：元认知反思
  → 模型
  → runIdleCycle：自主环 + 整理 + 梦境 carryover

模块一 · 自主性（要点）

  • 十种内驱力：好奇心、创造性、探索欲、掌控欲、连接欲、自主欲、意义欲、玩心、保护欲、创造欲
  • 交叉抑制矩阵：如 CONNECTION ↔ AUTONOMY、PROTECTION ↔ CONNECTION
  • Urge 冲动对象：生命周期、过期衰减、满足/过期；对接 INTENT_BEHAVIOR_MAP
  • 好奇心引擎：话题图谱、信息增益、未解问题；创造性模块：联想与隐喻
  • 自主行为环综合 DND、社交余量、能量、空闲时长；dreamCarryover 可触发 SPEAK

模块二 · 自我进化（要点）

  • 记忆按时间 gap 切成 episode，科学/亲密类加权建关联图
  • 梦境分浅睡/深睡/REM，高强度写 carryover 供主动轮开口
  • 人格轨迹记录五特质漂移与里程碑，与 PersonalityEvolution 双向同步
  • RL 桥接在上一轮 behaviorId 已知后更新 Q 值与 behaviorBias EMA

模块三 · 用户理解（要点）

  • 共情：识别 → 调节模式（shield / validate_first / warm_match 等）→ PAD 镜像
  • 心智模型：文本 + BDI 推断信念/欲望/意图，维护偏好图谱
  • 言外之意：掩饰、试探、撤回、求关注 → pendingNeed

模块四 · 具身化（要点）

  • 环境：场景标签、用户可用性 busy/away/distracted、情境压力
  • 时间感知：学习活跃节律、特殊日期与非常规时段
  • 表情映射：PAD 最近邻 → 7 种表情预设、6 档 Live2D sprite + CSS 滤镜

模块五 · 元认知（要点）

  • 信念四域 self / user / world / relationship，证据驱动修正
  • 反思环：习惯/回避/套话偏见检测，周期性洞察
  • 洞察经 insightToGoalInjection 写入 goalSystem（METACOG_INSIGHT）
  • 后置到 afterBehaviorDecision，与行为结果时序对齐
