## 投稿前自检（必做）

| 项 | 要求 | 你方注意 |
|----|------|----------|
| 查重 | CNKI ≤10% | 已有 GitHub 预印本，**投稿前用知网查重**；重复率高则改写引言/摘要或向编辑部说明 |
| 一稿多投 | 禁止 | 若已投其他刊，勿再投 |
| 盲审稿 | 删除 Word 中作者单位 | 系统上传**盲审版**；作者信息在系统单独填 |
| 署名 | 投稿后不可改 | 确认作者顺序与贡献 |
| 非涉密 + 版权转让 | 终审返修时上传 PDF 盖章 | 模板在官网「投稿须知」附件下载 |

## Word 排版步骤

1. 从官网下载 **《包装工程》投稿写作模板**、**参考文献著录格式**。  
2. 将 `包装工程-AMADEUS投稿稿.md` 内容粘贴进模板。  
3. 补全：**第一作者简介**、**通信作者**（本科生建议写导师为通信作者，若学校允许）、**基金项目**（无则写「无」）。  
4. 插入 **图1 系统流程**（可从 `AMADEUS-论文.md` §3.2 流程图重绘为黑白矢量图）、**表1–4** 按出现顺序编号。  
5. 英文题名、摘要、关键词与中文一一对应。  
6. 生成 **盲审稿**：删除正文页眉页脚中的姓名单位，保留「通信作者」占位勿留真名（按编辑部当年要求为准）。
