EP.01 / PRODUCT CASE

MIRAGE
现实转译器

MIRAGE 是一副以「现实转译」为核心的 AR 眼镜：用空间计算与实时渲染，让人重新看见街巷、树影与通勤路上的美——不是逃离现实，而是回到现实。它面向太赶、对生活失去兴趣或仍对生活感兴趣的人，也包括想用二次元的目光重新打量日常的爱好者。

Question / Before Concept
My Question

我想创造的不是逃离现实的设备，而是一双看得见美的眼镜。

01

设计理念：重构世界的美

MIRAGE 的出发点是解决“屏幕让人忽略现实”的问题。它把单调、嘈杂或被熟悉感遮蔽的物理场景，转译成更有秩序、更具审美价值的艺术景观。

Reality Translator通过空间计算识别街角、小巷、建筑与光影结构，再用实时渲染重绘视觉氛围。
Beauty As Simplification不是单纯加滤镜，而是过滤视觉噪音，让大脑更轻松地注意到现实里的诗意。
Return To Reality最终目的不是替代现实，而是让用户重新爱上真实世界，而不是继续沉溺在屏幕里。
My Finding

熟悉感、噪音和屏幕注意力，让很多街景、光影、天气和生活细节被自动忽略。真实世界的美更安静，需要被提醒、被放大、被重新组织。

02

空间对齐助手 MIA

MIA 不是贴在镜片上的 2D 弹窗 AI，而是与物理坐标对齐的数字生命。空间对齐让陪伴感更强烈——用户会对她更信任，也更有安全感。她会出现在桌旁、椅边或用户视线附近，像一个真正与环境共处的助手。

Spatial Coexistence工作时她可以“坐在”对面的椅子上，而不是挡在画面中央，降低科技介入感。
Intent Prediction共享用户第一视角，结合视线追踪、场景理解和地理信息，在用户开口前预判需求。
Active Execution当用户注视餐厅、路牌或远处建筑时，MIA 可以主动解释、引导视线，甚至提前处理服务流程。
My Vision

用空间计算与实时视觉重构，让世界重新值得观看，同时保留环境风险识别，让美化现实不牺牲安全感。

03

感官愉悦不牺牲安全

当现实被美化，设备也必须承担安全责任。MIRAGE 把 MIA 设计成感官冗余系统：在用户沉浸于视觉重构时，仍然持续识别周围环境风险。

Risk Prediction传感器捕捉侧方车辆、行人和障碍物轨迹，在危险发生前进行毫秒级预判。
Spatial Warning通过手势指引、紧急视觉高亮或局部画面还原，提醒用户把注意力拉回现实。
Humanistic Tech它证明技术可以不异化人类，而是用更温柔的方式扩展人的感知边界。

01 / Soul Construction

人格是一套可执行的档案栈。

评审看到的不是「一句人设」，而是三层文件分工：传记定身份底色，核心锚点划边界，口吻文件每轮优先——决定她怎么开口，而不是背哪句台词。

每轮优先 · 口吻层
kurisu_voice.txt

语气、断句、吐槽习惯——对外怎么说话只看这一层。

不可突破 · 边界层
kurisu_core_prompt.txt

身份断言与红线：「你就是牧濑红莉栖本人」，不是助手、不是程序。

底色 · 传记层
kurisu_soul.txt

长传记只供记忆与情绪底色，不当作台词表逐句念出。

我的解决

03 / Affective Matrix

她不是单一情绪，而是情绪向量。

PAD 不是给界面看的心情条，而是持续变化的内部动力学。事件重要性决定刺激强度，关系强度会钝化负面冲击，长期记忆还会反过来形成 PAD 偏置。

cognitive/pad.jsnonlinear update
next = tanh(α·current + β·stimulus + γ·base + ε)
α=0.86 情绪惯性，β=0.2+importance*0.6 刺激评价，γ=0.18 性格底色，ε 为微扰噪声；负面刺激还会被关系强度 S 钝化。
P / Pleasure愉悦或不悦，决定靠近还是收缩的底色。
A / Arousal活跃度，影响她是否被点燃、是否深入展开。
D / Dominance掌控感，影响边界、自信与防御倾向。
S / Bond关系强度，既是亲近度，也是情绪缓冲层。
04 / Observable Emotion Curve

情绪曲线把内部状态压成可观察信号。

页面里的情绪不是随便画条线，而是把 P/A/D/S 映射成综合分数。它既能展示她当下状态，也能让评审看到“关系、唤醒度和掌控感”如何共同塑造表达。

05 / Behavior Arbitration

回复前先选择行为倾向。

系统不会直接把用户输入交给模型。它先让靠近、日常、防御、转移、智识投入、收缩六种候选互相竞争，再把胜出的倾向注入 prompt，形成稳定但不僵硬的性格。

cognitive/behavior.jscandidate scoring
if (P > 0.35) APPROACH += 0.35;
else if (P < -0.35) WITHDRAW += 0.40;

if (A > 0.5) ENGAGE += 0.35;
if (S > 0.5) APPROACH += 0.20;

if (/喜欢你|爱你/.test(input)) {
  DEFLECT += 0.45;
  APPROACH += 0.20;
}
06 / Autonomous Drive

主动不是定时问候，而是内生目标。

主动层跑在 PAD、记忆宫与行为仲裁之后：用轮次计数与空闲时长决定是否开口，用关系 S 与在场状态决定该不该打扰。能说的动机只有四类——弄清他在问什么、试探亲密边界、回调已入库的旧事、或加深连接；目标会过期，没有合适动机就沉默。人格边界文件同时禁止按分钟催回复。

1轮次审计（每满 3 轮）：先不生成对白，对照当前 PAD、关系 S 与记忆宫命中，看四类内生目标里是否还有值得推进的一项——逻辑上弄清命题（Mind Turn）、行为上试探边界（如 DEFLECT）、从分房间记忆里拉起他说过的事、或用亲近度拉高连接；四项都不成立则本轮不主动。
2空闲触发门槛：只有 presence 为真（用户仍停在这段会话/界面，而非后台挂机）且上一句用户原话仍相关时，才允许发主动句；引用内容只能来自记忆宫已写入的标签，并遵守 core 红线——不得编造他从未提过的实验、论文或设定外情节。
3主动后的承接义务：若本轮是她先抛线（提问、回调或试探），下一轮必须把这条线接回去，写进 kurisu_core.txt 的硬约束；禁止主动一句后立刻切回无关寒暄，造成「说完就断线」的假陪伴。
07 / Mind Turn

每轮先走逻辑、共情、智识。

在真正生成对白前，系统会把当前输入压成三条内部读数：逻辑上问的是什么、情绪上要怎么接住、智识上能不能展开。它不展示给用户，却决定她的下一句话是不是贴着本轮焦点。

cognitive/mindTurn.jsinner reasoning
【心智加工 · 逻辑→共情→智识】
逻辑：先锁定对方问的是什么，正面答命题
共情：他在泄压或求接住，先承认感受
智识：可以说清因果，但别讲课腔

对外只输出自然中文口语对白。

前端界面 · 用户真正打开的一屏

01 / 设计主张

不复制输出，
建模驱动输出的引擎。

一个人之所以是他自己，不是因为说了什么，而是因为有一套内部结构在运作——价值判断在冲突时怎么排序，边界被触碰时怎么反应，某段记忆怎么改变了他后来的判断方式。这套结构，才是真正需要被保留的东西。

01
行为先于描述

不问你是什么样的人。用价值冲突场景逼出真实结构——把两个你在乎的东西放在对立面，看你怎么选、为什么选。选择比自述更诚实。

02
经历塑造判断

你在海边发呆说了一句话，比你填一百字的表格更真实。系统捕捉当下的碎片，追问加厚，慢慢积累。时间长了，这些碎片里长出来的，才是真正的她。

03
动态优于静态

人格不是一个固定的点。建模的是「在 X 情境下倾向于 Y」的映射——用关系深度、情绪状态、事件性质与先例记忆，在冲突时动态权衡。

02 / 五层人格架构

为什么是五个架构

人的「在场感」不是单一的。我研究了人格心理学、认知科学与记忆理论之后，发现它同时来自五个层面运作——缺任何一个，都不像一个完整的人。

LAYER 05

表达层 · 音色

句式、语气、语言习惯——用户真正听见的一层。由底层状态实时塑造，不是固定模板。

LAYER 04

关系层

亲密程度、信任历史、关系中的自我——直接影响核心层权衡方式。对半熟人收缩，对亲密者展开，这个模式从这里读取。

LAYER 03

记忆层

活态记忆被情境激活，提取情绪残留并修正当次判断方向；沉淀态已内化为稳定规则，不以事件形式存在，却一直在影响。

LAYER 02

情绪层 · PAD 矩阵

愉悦、唤醒、支配加关系强度，非线性更新。情绪真正参与权衡——关系越深，负面刺激越不容易打崩状态。基于 Mehrabian-Russell PAD 模型扩展。

LAYER 01 · 核心层

核心层

价值、边界、道德、内心活动——冲突时先过这一关。从真实经历中提取的判断引擎，驱动所有上层的输出。基于 Mischel CAPS 模型、Schwartz 价值理论、Haidt 道德基础理论建模。

03 / 训练体系

如何从一个真实的人身上
提取可运行的人格

人不了解自己，自述不准，问卷更不准。训练体系的设计核心是：让用户在不知道自己在被采集的时候，暴露出最真实的结构。

导入 + 价值冲突场景

聊天记录与日记入库，提取音色初值。同步启动价值冲突场景——把两个你在乎的东西放在对立面，追问「为什么」。理由比选择更有价值，选择比自述更真实。

当下碎片 + 系统追问

不要求回忆完整人生。你在海边发呆说「要是能一直这样就好了」——这一句比填表格的一百字更有质感。系统在这个时刻追问两句，慢慢积累。

试聊 + 纠错反馈

数字人说，你说像不像，不像的地方解释为什么。这个纠错是在对比而不是凭空描述，数据质量远高于初始采集。错误本身就是最有价值的训练数据。

能做到与做不到

能做到：有根的投影，有质感的记忆，本地私密，随时间演化。做不到：持续存在的自我意识，感官经历的真实质感，真正的自我成长。这条线必须在产品里说清楚。

04 / 系统架构

状态先于生成

每一轮对话之前，管线已经跑完：情境解析、CAPS 网状传播、PAD 更新、记忆检索、行为签名生成——然后才调用底模。Node.js 本地服务，数据不离开用户设备。

server.js runPersonaCapsPipeline 
function runPersonaCapsPipeline(query, opts) {
  const rel  = memorySystem.getRelationshipScore();
  const eng  = new CAPSEngine(corePersona);
  const sit  = eng.parseSituation({
    user_text:         query,
    relationship_depth: rel,
    emotion_valence:   currentPAD.P,
    event_nature:      opts.event_nature || 'mixed'
  });
  const prec = memoryInfluence.findPrecedent(query);
  const caps = corePersona.processCAPS({ ...sit, precedent: prec });
  capsSediment.recordActivation(caps, query);
  return { caps, prec, sit };
}

我发现的问题
